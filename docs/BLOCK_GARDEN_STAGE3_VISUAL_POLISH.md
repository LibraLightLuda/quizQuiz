# 빈칸 정원 3단계 비주얼·플레이 감각 기록

작성 기준일: 2026-08-30
기준 구현: `docs/BLOCK_GARDEN_STAGE2_IMPLEMENTATION.md`

## 선택한 방향: 손으로 가꾸는 작은 입체 정원

빈칸 정원은 빠른 반사 신경보다 다음 자리를 생각하는 공간 퍼즐이다. 그래서 번쩍이는 아케이드 표현보다, `부드러운 배경 → 손에 잡히는 흙판 → 선명하게 자라는 조각 → 짧고 기분 좋은 보상`의 순서로 시선을 안내한다.

- 비어 있는 칸은 따뜻한 아이보리 토양으로, 보드는 짙은 초록 테두리와 깊이감으로 구분한다.
- 조각은 색과 기호를 함께 사용하고, 작은 입체 그림자와 하이라이트로 손에 집히는 물체처럼 보이게 한다.
- 화면의 가장 큰 숫자는 현재 점수다. 최고 점수는 한 단계 약하게 두어 현재 플레이를 방해하지 않는다.
- 장식 이미지를 새로 늘리지 않고 CSS와 기존 벡터 아이콘으로 통일했다. 외부 상용 게임의 자산·연출을 닮지 않으면서도 앱 용량과 오프라인 동작을 지킨다.

## 가장 큰 체감 개선

- **배치 전 판단**: 도형 중심이 손가락 아래에 오도록 드래그하고, 보드가 살짝 떠오른다. 가능한 칸은 초록 외곽선·그림자·색 채움으로, 불가능한 칸은 붉은 줄무늬로 즉시 구분한다.
- **착지와 점수**: 놓인 조각은 짧게 튀어 오르고, 현재 점수는 커지며 `+점수`가 위로 떠오른다. 빈칸 수와 사용 완료 조각도 동시에 바뀌므로 결과를 한눈에 읽을 수 있다.
- **줄 제거**: 제거 칸은 밝은 빛과 짧은 팽창을 거쳐 비워지고, 보드는 한 번만 밝아진다. 성공음은 짧은 상승 멜로디로 재생하며, 동시·연속 제거일수록 피치를 높인다. 콤보는 상태 카드에서만 가볍게 살아나므로 게임 속도를 늦추지 않는다.
- **터치 편안함**: 선택 조각은 위로 떠서 현재 선택을 분명히 보이고, 드래그·탭·키보드 흐름은 유지했다. 홈의 아래쪽 카드에서 시작했을 때도 게임은 항상 화면 맨 위에서 열린다.
- **반응형 배치**: 세로 모바일은 보드 중심의 한 열, 낮은 데스크톱은 보드와 조각함을 나란히 배치한다.

## 의도적으로 임시로 남긴 것

- 제거 때의 파티클·전용 음향·햅틱은 아직 넣지 않았다. 지금의 짧은 CSS 반응이 실제 플레이를 늦추지 않는지 먼저 확인한 뒤 추가한다.
- 게임오버 화면과 시작 안내 화면은 플레이 화면보다 연출 밀도가 낮다. 게임오버 결과에는 최고 기록과 다음 판의 작은 점수 목표를 표시한다.
- 실제 장기 플레이 데이터에 맞춘 콤보 연출 강도와 점수 효과 빈도는 아직 조정 전이다.

## 검수 결과와 다음 확인

- 390×844 모바일에서 점수·보드·세 조각과 안내가 한 화면에 읽히는지 확인했다.
- 1280×720 낮은 데스크톱에서 보드·조각함·점수 정보가 함께 보이는지 확인했다.
- 320×568에서는 세로 스크롤이 필요하지만, 진입 시 상단부터 시작해 점수와 보드가 잘리지 않도록 수정했다.
- 실제 탭과 드래그 배치에서 착지, 점수 플로팅, 사용 완료 조각 표시를 확인했다.

최종 출시 전에는 저사양 Android에서 연속 배치·여러 줄 제거 때 프레임 저하가 없는지, 동작 줄이기 설정에서 모든 장식 애니메이션이 멈추는지, 색각 다양성 환경에서 미리보기와 무효 위치가 충분히 구분되는지를 특히 확인한다.
