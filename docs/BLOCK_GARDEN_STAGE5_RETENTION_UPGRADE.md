# 빈칸 정원 5단계 — 전략성·재방문 구조 개선

## 목적

Block Blaster의 일일 도전과 다음 수 계획 요소에서 영감을 받되, 원작의 명칭·수집물·표현을 복제하지 않고 빈칸 정원의 정원 테마에 맞는 장기 목표를 추가했다.

## 구현 범위

- **다음 새싹**: 현재 조각 묶음을 모두 사용한 뒤 다음 묶음의 첫 조각으로 등장할 조각을 미리 표시한다. 기존 저장 판에는 다음 조각이 없을 수 있으므로 재개 시 안전하게 보충한다.
- **오늘의 정원**: 날짜별 시드로 동일한 조각 공급을 재현하는 12줄 도전 모드다. 목표 달성 즉시 결과를 기록하며, 완료한 날짜는 로컬 기록에 남긴다.
- **주간 목표**: 완료한 판의 줄 제거 수를 주간 40줄 목표로 집계한다.
- **기록 가독성**: 최고 콤보와 한 번에 제거한 최대 줄 수를 결과 화면에 표시한다.
- **첫 플레이 안내**: 첫 배치 전 핵심 조작을 알려 주는 안내 카드를 제공한다. 작은 모바일 화면에서는 조각함을 가리지 않도록 숨기고 기존 안내 문구를 유지한다.
- **감각 피드백**: 줄 제거 시 기존 상승 효과음에 더해 지원 기기에서 짧은 진동을 제공한다.

## 중요한 설계 판단

1. 다음 조각은 별도 조각을 덧붙이지 않고, 다음 조각 묶음의 첫 칸으로 소비한다. 따라서 미리보기와 실제 공급이 어긋나지 않는다.
2. 일일 모드는 별도 보드 규칙을 만들지 않고 기존 무한 규칙을 재사용한다. 12줄 달성으로 종료하여 콘텐츠 제작과 밸런스 범위를 제한했다.
3. 일일 진행의 조각 순서는 `randomState`를 저장해 새로고침 뒤에도 유지한다. Classic 모드는 기존 암호학적 난수를 그대로 사용한다.
4. 기존 저장 데이터의 `schemaVersion`은 유지하고 새 필드는 선택적으로 읽는다. 이전 진행 판과 기록을 버리지 않기 위한 호환 방식이다.

## 검증

- 단위 테스트 190개 통과
- 전체 E2E 156개 통과
- Block Garden 전용 모바일·데스크톱 E2E 22개 통과
- TypeScript/Vite 빌드 및 번들 예산 통과
- PWA 테스트는 코드 문제가 아니라 Windows Defender가 로컬 4176 포트를 점유한 환경 문제로 실행 불가
