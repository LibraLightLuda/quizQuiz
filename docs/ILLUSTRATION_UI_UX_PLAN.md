# 어린이 학습 놀이터 일러스트·UI/UX 품질 개선 계획

## 1. 목표와 변경 원칙

이 계획의 목표는 수학·한국어·영어·기억력 챌린지·이야기 탐험대·스도쿠의 모든 콘텐츠를 유치원생과 초등학생이 혼자서도 이해하고 즐길 수 있는 시각·사용 경험으로 끌어올리는 것이다.

### 구현 진행 기록

2026-08-22 첫 구현 묶음:

- 공통 시각 자산 manifest와 자체 SVG 학습 아이콘 6종을 추가했다.
- 앱 안내 캐릭터 `모리`를 가벼운 자체 SVG로 구현해 홈·기억력·이야기에서 재사용할 기반을 만들었다.
- 모바일 홈을 `오늘의 추천 → 모든 학습 2열 타일` 구조로 개선했다.
- 수학 쉬움 문제에 피연산자와 연산에 맞춰 생성되는 수량 SVG를 적용했다.
- 대표 이야기 `비 오는 날의 우산`의 연속 장면 3개와 표지 미리보기를 실제 그림책 일러스트로 교체했다.
- 일러스트 manifest 파일 존재·대체 텍스트와 수학 보조 그림 노출 범위를 자동 검증한다.

2026-08-22 두 번째 구현 묶음:

- 새싹 단계 이야기 6편 전체에 연속 장면 18개와 표지 미리보기를 완성했다.
- 같은 이야기 안에서는 인물·옷·장소·핵심 소품을 유지해 읽기와 순서 맞추기의 시각 단서가 일관되게 보이도록 했다.
- 모든 새 그림을 768×768로 최적화하고 PWA 자산 목록과 대체 텍스트 자동 검증 범위를 18개 장면으로 넓혔다.

2026-08-22 세 번째 구현 묶음:

- 한국어·영어·기억력이 함께 쓰는 공통 개념 그림 사전을 시작하고 `사과`, `강아지`, `도서관`, `기쁨` 4종을 먼저 연결했다.
- 빈칸 문제에는 뜻 그림을 보여 주고, 듣기 문제에는 정답 피드백 뒤에만 그림을 공개해 듣기 학습을 방해하지 않도록 했다.
- 기억력 카드에서는 낱말 쪽과 설명 쪽에 같은 그림을 반복하지 않고 설명·뜻 쪽에만 개념 그림을 넣었다.
- 수학 기억력의 20 이하 정답 카드에는 숫자와 수량 점을 함께 보여 주고, 카드 뒷면 물음표를 자체 기억력 문양으로 교체했다.

2026-08-22 네 번째 구현 묶음:

- 공통 개념 사전을 12종으로 확대해 `학교`, `친구`, `가족`, `선생님`, `아침`, `저녁`, `봄`, `가을`을 추가했다.
- 영어와 한국어 문제 11개 단어 ID, 기억력의 한국어·영어 20개 의미 쌍이 공통 그림을 재사용하도록 연결했다.
- 기억력 정답 문구에 선택한 두 카드의 `낱말 ↔ 뜻` 관계를 직접 표시해 성공 이유를 확인할 수 있게 했다.
- 모든 수학 기억력 정답을 10묶음과 낱개 형태로 표시하도록 수량 시각화를 99까지 확장했다.
- 이야기 표지는 256×256 전용 썸네일로 분리하고, 큰 콘텐츠 그림은 사용 후 런타임 캐시에 저장하도록 바꿔 최초 PWA 설치 용량을 줄였다.

2026-08-22 다섯 번째 구현 묶음:

- 공통 개념 사전을 32종으로 확대하고 연필, 우산, 병원, 직업, 성격, 행동처럼 남아 있던 기억력 개념 20종을 추가했다.
- 한국어 기억력 20쌍과 영어 기억력 20쌍 모두에 의미 그림을 연결해 수학의 수량 그림까지 포함한 전체 60쌍의 시각 단서 누락을 없앴다.
- 같은 그림을 양쪽 카드에 반복하지 않고 뜻·설명 카드에만 보여 주는 관계형 원칙을 유지했다.
- 한국어·영어 일반 학습에서도 같은 단어 ID가 있는 연필, 병원, 요리사, 소방관 그림을 공통으로 재사용하도록 연결했다.
- 언어 기억력 40쌍의 그림 연결과 32개 자산 manifest를 자동 검사하도록 회귀 테스트를 강화했다.

2026-08-22 여섯 번째 구현 묶음:

- 틀린 숫자를 고르면 실제로 겹치는 숫자와 목표 칸을 × 표시, 무늬, 테두리로 함께 보여 주어 색만으로 판단하지 않게 했다.
- 숫자판에서 현재 칸과 겹치는 선택지를 점선과 × 표시로 구분하고 `겹침` 문구를 유지했다.
- 지우기, 힌트, 새 퍼즐을 자체 SVG 아이콘으로 통일하고 튜토리얼 완료 화면에 각 도구의 사용법을 추가했다.
- 퍼즐 완료 표시를 체크가 그려진 스도쿠 판으로 바꾸고 동작 줄이기 설정을 따르는 축하 연출을 유지했다.
- 규칙 그림, 도구 그림, 충돌 안내와 기존 무작위 입력 방지를 단위·화면 테스트로 검증한다.

## 3. 대상 연령별 UX 원칙

### 유치원·예비 초등

- 한 화면에는 핵심 질문 하나와 대표 행동 하나만 둔다.
- 본문 22px 이상, 버튼 글자 18px 이상, 터치 영역 56px 이상을 기본으로 한다.
- 모든 핵심 안내에 `듣기`를 제공하고, 음성 재생 버튼은 같은 위치와 모양을 유지한다.
- 글자보다 그림을 먼저 보여 주되 정답을 그대로 노출하는 그림은 사용하지 않는다.
- 타이머는 숫자 압박보다 천천히 줄어드는 친근한 시각 표시로 보여 준다.
- 난이도는 학년만 쓰지 않고 `처음`, `차근차근`, `도전`처럼 아이가 이해하는 말과 그림을 함께 쓴다.

### 초등 1~3학년

- 그림과 짧은 문장을 같은 비중으로 제공한다.
- 선택 전 예시 한 개를 볼 수 있게 하고, 틀린 뒤에는 관련 장면이나 핵심 부분을 강조한다.
- 진행 단계와 남은 활동 수를 점·길·스티커 형태로 명확하게 보여 준다.
- 연속 성공은 격려하되 속도보다 정확성과 다시 생각하기를 우선한다.

### 초등 4~6학년

- 그림은 장식보다 정보 도식, 관계, 근거 표시 중심으로 사용한다.
- 한 화면 정보량을 조금 늘리되 주요 행동은 하나로 유지한다.
- 기록, 도감, 도전 배지는 선택적으로 강조하고 유아적인 캐릭터 연출은 줄인다.
- 긴 이야기에서는 근거 문장과 장면을 빠르게 오갈 수 있게 한다.

## 4. 일러스트 디자인 시스템

### 시각 방향

- 스타일: 둥근 형태의 부드러운 2D 벡터, 종이 오리기 느낌의 얕은 명암, 깨끗한 외곽선
- 분위기: 밝고 따뜻하지만 과도하게 장난감처럼 보이지 않는 학습 그림책
- 캐릭터: 다양한 피부색·가족 형태·신체 특성을 자연스럽게 포함하고 직업 성별 고정관념을 피함
- 표정: 기쁨, 고민, 놀람, 아쉬움, 안도 등 학습에 필요한 감정을 눈과 자세로 분명하게 표현
- 배경: 저연령은 핵심 대상만, 고학년은 원인·결과를 찾을 수 있을 만큼 맥락을 추가
- 선과 색: 색약 모드에서도 경계가 보이도록 외곽선과 명도 차이를 유지

### 공통 캐릭터와 시각 언어

- 앱 전체를 안내하는 중립적인 탐험대 캐릭터 1종과 표정·동작 12종을 만든다.
- 수학, 한국어, 영어, 기억력, 이야기, 스도쿠는 각각 고유 색과 도구를 갖되 같은 그림체를 사용한다.
- 성공은 별, 반짝임, 캐릭터 자세를 함께 사용하고 오답은 주황 테두리와 생각하는 표정으로 표현한다.
- 아이콘은 운영체제 이모지가 아니라 자체 SVG 세트로 교체해 iOS·Android·PC에서 동일하게 보이게 한다.

### 자산 형식과 성능

- 버튼·상태·과목 아이콘은 SVG로 제작한다.
- 이야기 장면과 큰 삽화는 AVIF를 우선하고 WebP 대체 파일을 제공한다.
- 1개 큰 장면은 모바일 기준 AVIF 80KB 이하, WebP 140KB 이하를 목표로 한다.
- 모든 자산에 고유 ID, 비율, 대체 텍스트, 대상 연령, 사용 위치를 기록한 manifest를 둔다.
- 화면에 들어올 자산만 지연 로드하고 현재 장면의 앞뒤 한 장만 미리 불러온다.
- 오프라인 캐시는 핵심 UI 자산을 선캐시하고 콘텐츠 그림은 사용한 묶음 단위로 런타임 캐시한다.
- 이미지 실패 시 의미가 유지되는 자체 SVG 자리표시자와 텍스트를 제공한다.

## 5. 콘텐츠별 일러스트 개선 범위

### 5.1 홈·공통 화면

제작 항목:

- 앱 대표 캐릭터 1종, 표정·동작 12종
- 6개 메인 학습 모드 대표 삽화
- 설정 3종, 이어하기, 오늘의 도전, 오프라인, 기록 없음 상태 아이콘
- 성공·콤보·배지·새 기록용 짧은 애니메이션 8종

적용 방식:

- 홈 카드에는 기호 하나 대신 `무엇을 하는 학습인지` 보이는 작은 장면을 넣는다.
- 결과 화면은 과목별 배경과 획득 스티커를 달리해 반복 플레이의 보상을 구분한다.
- 모든 애니메이션은 `동작 줄이기`에서 정지 이미지로 대체한다.

### 5.2 수학

정답이나 문제 범위는 바꾸지 않고 난이도별 보조 시각물만 추가한다.

- 덧셈: 10칸 모형, 점 묶음, 두 바구니 합치기
- 뺄셈: 물건이 빠져나가는 장면, 수직선 뒤로 이동
- 곱셈: 같은 개수의 묶음과 배열
- 사칙연산: 연산 기호별 색·형태 표지와 짧은 예시
- 쉬움에서는 문제 아래에 `그림으로 보기`를 기본 노출하고, 보통 이상은 선택형 힌트로 제공
- 결과 복습에서는 틀린 문제만 식과 수 모형을 나란히 표시

수량 그림은 정적 이미지 수백 개를 만들지 않고 숫자와 연산에 맞춰 SVG로 안전하게 생성한다.

### 5.3 한국어

- 144개 단어 모두에 의미가 하나로 읽히는 개념 그림을 연결한다.
- 현재 이모지가 있는 59개 항목도 자체 그림으로 교체하고, 나머지 85개를 신규 제작한다.
- 사물·동물·음식은 단일 대상 그림, 장소·직업·추상어는 짧은 상황 장면으로 표현한다.
- 빈칸 문제에서는 그림이 정답 글자를 직접 암시하지 않고 단어의 뜻만 도와야 한다.
- 듣기 문제는 그림을 선택지에 쓰지 않고, 정답 후 복습 카드에서 단어·음성·그림을 함께 보여 준다.
- 받침과 음절 묶음은 색만 달리하지 않고 밑줄·칸·입 모양 아이콘을 함께 사용한다.

### 5.4 영어

- 145개 단어 모두를 공통 개념 사전에 연결한다.
- 한국어 단어와 겹치는 `apple/사과`, `library/도서관` 같은 항목은 같은 그림을 공유한다.
- 동사·형용사는 한 대상 그림 대신 행동이나 전후 비교 장면으로 표현한다.
- 듣기 문제에서는 먼저 소리를 듣고 고르게 하며, 그림은 힌트 또는 정답 피드백에서 단계적으로 공개한다.
- 정답 후에는 영어 단어, 한국어 뜻, 그림, 다시 듣기를 한 장의 복습 카드에 묶는다.
- 철자 빈칸은 글자 간격과 빈칸 위치를 더 선명하게 하고 대소문자 혼동을 막는 글꼴을 사용한다.

### 5.5 기억력 챌린지

60개 의미 쌍을 단순 동일 그림 짝으로 만들지 않는다.

- 수학: `식 카드 ↔ 숫자·수량 카드`
- 한국어: `낱말 카드 ↔ 뜻이 드러나는 상황 그림과 짧은 설명 카드`
- 영어: `영어 낱말·발음 카드 ↔ 한국어 뜻과 개념 그림 카드`
- 통합: 카드 위쪽의 과목 모양 표지를 유지해 읽기 전에도 유형을 구분할 수 있게 한다.
- 뒤집힌 카드는 물음표 하나 대신 자체 패턴, 번호, 과목 중립 문양을 사용한다.
- 앞면 글자 크기는 카드 수에 따라 지나치게 작아지지 않도록 최소 14px을 보장한다.
- 최고 단계에서는 카드 크기를 줄이는 대신 보드 스크롤 또는 단계별 판 나누기를 사용자 테스트로 비교한다.
- 두 카드의 관계가 맞았을 때 연결선을 잠깐 보여 주어 왜 한 쌍인지 설명한다.

### 5.6 이야기 탐험대

가장 큰 일러스트 우선순위다.

- 24편 각각에 1개의 표지 삽화를 만든다.
- 새싹 18장면, 한걸음 24장면, 탐험가 30장면, 생각왕 36장면으로 총 108개 장면 삽화를 만든다.
- 이야기마다 인물의 얼굴, 옷, 소품, 장소를 고정한 1장짜리 스타일 시트를 먼저 만든다.
- 장면 그림에는 해당 문장의 주어·행동·대상이 반드시 보여야 한다.
- 순서 찾기에서는 원본 장면의 축소판을 사용해 시각 기억과 문장 기억을 함께 돕는다.
- 감정 문제는 표정만 과장하지 않고 상황과 몸짓까지 포함한다.
- 원인·결과·근거 문제는 답을 노출하지 않으면서 관련 단서를 그림 안에 남긴다.
- 고학년 이야기에는 장식 삽화보다 지도, 실험 조건, 인물 관계 같은 정보 그림을 사용한다.
- 표지는 동일한 이야기의 장면을 단순 확대하지 않고 제목과 주제를 보여 주는 별도 구도로 제작한다.

### 5.7 스도쿠

- 튜토리얼 안내 캐릭터의 가로 보기, 세로 보기, 상자 보기, 모두 확인 동작 4종을 만든다.
- 강조 영역은 색과 함께 굵은 테두리, 화살표, 패턴을 사용한다.
- 긴 규칙 요약은 한 번에 보여 주지 않고 현재 단계와 관련된 한 문장 카드로 나눈다.
- 실제 퍼즐 화면은 장식을 최소화하고 힌트·메모·지우기 아이콘만 자체 SVG로 통일한다.
- 잘못된 숫자는 흔들림만 주지 않고 충돌한 칸 두 곳을 같은 모양 표지로 연결한다.
- 완성 시 판이 작은 축하 그림으로 변하는 짧은 연출을 제공한다.

## 6. 공통 UI/UX 구조 개선

### 홈

- 최상단에 `이어서 하기` 또는 `오늘의 추천` 한 개를 가장 큰 카드로 배치한다.
- 전체 학습은 2열 큰 타일로 배치하되 320px에서는 한 열로 전환한다.
- 최초 사용 시 `글을 아직 천천히 읽어요 / 혼자 읽을 수 있어요`를 선택하게 하고 설정에서 변경 가능하게 한다.
- 저연령 설정에서는 카드 설명을 한 줄로 줄이고 음성 안내 버튼을 보여 준다.
- 최근 결과는 홈의 핵심 선택 아래 작은 접이식 카드로 이동한다.

### 모드·난이도 선택

- 선택 → 난이도 → 시작의 세 단계를 상단 점 표시로 보여 준다.
- 현재 선택의 예시 문제 또는 미리보기 한 개를 제공한다.
- 학년 표시는 보호자에게는 유지하되 아이가 읽는 첫 문구는 `처음`, `차근차근`, `도전`처럼 바꾼다.
- 시작 버튼은 화면 아래 safe area 위에 고정하되 콘텐츠를 가리지 않도록 여백을 확보한다.
- 추천 이유를 `지난번에 잘했어요`, `처음이라 추천해요`처럼 짧게 설명한다.

### 문제 풀이

- 상단에는 나가기, 진행도, 시간만 남기고 보조 정보는 접는다.
- 질문, 그림, 보기 순서를 모든 과목에서 통일한다.
- 듣기 버튼은 항상 같은 위치에 두고 재생 중임을 파동과 글자로 함께 표시한다.
- 첫 오답 뒤에는 같은 보기를 반복 누를 수 없게 하고 짧은 시각 힌트를 제공한다.
- 두 번 틀리면 관련 학습 설명을 보여 준 뒤 다시 선택하게 한다.
- 제한 시간이 임박해도 빨간색·경고음 대신 차분한 주황색과 짧은 안내를 사용한다.

### 결과·기록

- 가장 먼저 `무엇을 배웠는지` 한 문장으로 알려 준다.
- 점수보다 별, 정확도, 다시 볼 항목을 먼저 보여 준다.
- `다시 하기`, `틀린 것 연습`, `다른 학습` 중 한 개를 추천 행동으로 강조한다.
- 기록은 어린이 화면에서는 스티커북, 보호자 보기에서는 시간·정확도 표로 제공한다.

### 설정과 보호자 영역

- 어린이가 자주 쓰는 음성·효과음은 일반 설정에 유지한다.
- 기록 초기화, 난이도 범위, 시간 설정 같은 항목은 길게 누르기나 간단한 보호자 확인 뒤에 둔다.
- TTS가 지원되지 않을 때 기술 용어 대신 `이 기기에서는 목소리를 들려주기 어려워요`라고 안내한다.

## 7. 정보 구조와 컴포넌트 작업

### 공통 데이터 구조

```text
VisualAsset
├─ id
├─ conceptId 또는 storySceneId
├─ kind: icon | concept | scene | reward | guide
├─ src / fallbackSrc
├─ aspectRatio
├─ altKo
├─ ageBands
└─ dominantColor
```

- 한국어·영어·기억력에서 공통 `conceptId`를 사용해 중복 그림을 제거한다.
- 이야기 장면은 `storyId + sceneId`로 연결하고 표지는 별도 자산으로 관리한다.
- 화면 코드에 파일 경로를 직접 쓰지 않고 자산 manifest를 통해 불러온다.

### 공통 컴포넌트

- `LearningTile`: 홈과 모드 선택의 큰 그림 카드
- `IllustratedPrompt`: 질문·그림·듣기 버튼을 묶은 카드
- `ConceptPicture`: 개념 그림과 대체 텍스트, 로딩·실패 상태
- `KidProgress`: 점·길·스티커형 진행 표시
- `CoachMessage`: 안내 캐릭터와 한 문장 도움말
- `RewardMoment`: 모션 설정을 따르는 성공 연출
- `StickyPrimaryAction`: safe area를 고려한 하단 대표 버튼

## 8. 제작·개발 단계

일정은 디자인 1명, 일러스트 1명, 프런트엔드 1명을 기준으로 한 10주 권장안이다. 인력이 다르면 주차보다 단계의 순서를 유지한다.

### 0단계 — 기준 확정과 자산 목록화, 1주

- 모든 화면과 상태를 캡처해 현행 기준선을 만든다.
- 144개 한국어, 145개 영어, 60개 기억력 쌍의 중복 개념을 묶어 공통 개념 목록을 확정한다.
- 24편 이야기의 인물·장소·소품 연속성 표를 작성한다.
- 색, 선, 그림체, 인물 표현, 금지 표현이 포함된 스타일 가이드를 승인한다.
- 유치원, 초등 저학년, 초등 고학년 각 3명 이상으로 핵심 흐름을 관찰한다.

완료 산출물: 화면 인벤토리, 공통 개념 사전, 이야기 스타일 시트 목록, 디자인 토큰 초안, 사용자 테스트 기준선.

### 1단계 — 공통 UI와 홈, 1주

- 자체 SVG 아이콘과 대표 캐릭터를 적용한다.
- 홈 정보 구조를 오늘의 추천·이어하기 중심으로 재구성한다.
- 공통 버튼, 카드, 진행도, 음성, 피드백, 결과 컴포넌트를 통일한다.
- 320·390·768px과 가로 화면에서 레이아웃을 고정한다.

완료 기준: 첫 화면에서 대표 학습과 전체 학습 진입이 모두 가능하고, 핵심 버튼이 56px 이상이며 가로 넘침이 없다.

### 2단계 — 이야기 탐험대, 3주

- 24개 표지와 108개 장면을 이야기별 묶음으로 제작한다.
- 우선 4단계 대표 이야기 1편씩을 완성해 그림 이해도 테스트를 진행한다.
- 검증된 스타일로 나머지 20편을 배치 제작한다.
- 읽기, 순서, 감정, 원인·결과, 근거 화면에 장면 이미지를 연결한다.

완료 기준: 그림만 순서대로 보아도 주요 사건을 설명할 수 있고, 인물·소품 불일치가 없으며 모든 장면에 대체 텍스트가 있다.

### 3단계 — 한국어·영어·기억력, 3주

- 공통 개념 사전 기준으로 단어 그림을 제작한다.
- 한국어 144개와 영어 145개의 연결 누락을 0개로 만든다.
- 기억력 60쌍은 양쪽 카드가 동일 그림이 되지 않도록 관계형 구도를 제작한다.
- 정답 후 복습 카드와 듣기 흐름을 개선한다.

완료 기준: 모든 항목에 그림 또는 명시적으로 승인된 정보 도식이 있고, 그림만으로 잘못된 복수 정답이 생기지 않는다.

### 4단계 — 수학·스도쿠·성취, 1주

- 수학 수 모형을 동적 SVG로 구현하고 난이도별 노출 규칙을 적용한다.
- 스도쿠 튜토리얼과 충돌 안내를 시각적으로 개선한다.
- 과목별 스티커와 결과 연출을 적용한다.

완료 기준: 보조 그림이 정답을 대신하지 않고 개념 이해를 돕고, 스도쿠 규칙을 음성·그림만으로도 따라 할 수 있다.

### 5단계 — 통합 검증과 배포, 1주

- 실제 iPhone Safari, Android Chrome, 태블릿, 데스크톱에서 검증한다.
- 오프라인 첫 재방문, 느린 네트워크, 이미지 실패, 새로고침 복구를 검사한다.
- 사용자 테스트 결과를 반영하고 회귀 테스트 후 단계적으로 배포한다.

완료 기준: 아래 품질 게이트를 모두 통과하고 기존 학습 기능 회귀가 없다.

## 9. 품질 게이트

### 어린이 사용성

- 유치원 사용자 80% 이상이 보호자 도움 없이 추천 학습을 시작한다.
- 초등 저학년 사용자 90% 이상이 뒤로 가기, 듣기, 답 선택, 다음 문제를 스스로 수행한다.
- 첫 사용자가 10초 안에 현재 화면에서 해야 할 행동을 설명할 수 있다.
- 실수로 인한 이탈과 동일 오답 반복이 기존 기준선보다 감소한다.

### 시각·접근성

- 본문과 버튼 글자는 WCAG AA 대비 4.5:1 이상, 큰 글자는 3:1 이상을 충족한다.
- 상태는 색 이외의 모양·아이콘·텍스트로도 구분된다.
- 모든 정보성 이미지에 정확한 한국어 대체 텍스트가 있다.
- VoiceOver와 TalkBack에서 읽기 순서가 시각 순서와 일치한다.
- 200% 글자 확대, 동작 줄이기, 색각 이상 시뮬레이션에서 기능 손실이 없다.

### 반응형·터치

- 320×568, 390×844, 768×1024, 1280×800 및 모바일 가로 화면에서 가로 스크롤이 없다.
- 주요 터치 대상은 56×56px, 보조 대상은 최소 44×44px이다.
- 하단 고정 버튼은 iOS safe area와 키보드에 가려지지 않는다.
- 카드 뒤집기, 순서 바꾸기, 스도쿠 숫자 선택이 한 손 터치로 가능하다.

### 성능·오프라인

- 초기 홈 화면 압축 전송량은 500KB 이하를 목표로 한다.
- 저사양 모바일에서 화면 전환과 카드 뒤집기가 끊기지 않는다.
- 이야기 장면은 필요한 묶음만 내려받고 사용한 콘텐츠는 오프라인에서 다시 열린다.
- 이미지 로딩 실패 시 문제, 정답, 진행 상태가 사라지지 않는다.

### 회귀 방지

- 기존 단위 테스트, 전체 E2E, PWA 오프라인 테스트가 모두 통과한다.
- 수학·한국어·영어의 같은 seed 문제에서 정답과 선택지가 변경되지 않는다.
- 기존 로컬 저장 기록을 새 버전에서 읽을 수 있다.
- 기억력 iOS 카드 뒤집기와 스도쿠 무작위 입력 방지 테스트를 유지한다.

## 10. 우선순위

### P0 — 가장 먼저

1. 공통 시각 스타일과 자산 manifest
2. 홈의 긴 목록과 저연령 시작 흐름 개선
3. 이야기 24편·108장면의 실제 일러스트
4. 한국어·영어 공통 개념 사전과 필수 쉬움 단계 그림
5. 실제 모바일 접근성·성능 기준 자동화

### P1 — P0 직후

1. 한국어·영어 전체 단어 그림 완성
2. 기억력 60쌍의 관계형 그림
3. 수학 동적 수 모형
4. 스도쿠 튜토리얼 안내 그림
5. 과목별 결과·배지·도감 연출

### P2 — 데이터 확인 후

1. 읽기 수준에 따른 화면 밀도 자동 조절
2. 보호자용 학습 기록 보기
3. 자주 틀리는 개념에 맞춘 시각 힌트 추천
4. 시즌별 배지와 이야기 표지 변형

## 11. 구현 전 최종 결정 항목

- 대표 캐릭터를 사람형, 동물형, 비생물형 중 어떤 방향으로 만들지
- 그림 제작을 전부 자체 벡터로 할지, 장면만 래스터 일러스트로 혼합할지
- 최초 읽기 수준 선택을 필수로 할지 건너뛸 수 있게 할지
- 고학년 화면에서 캐릭터 노출을 어느 정도까지 줄일지
- 108개 이야기 장면을 한 번에 배포할지 단계별 콘텐츠 팩으로 배포할지
