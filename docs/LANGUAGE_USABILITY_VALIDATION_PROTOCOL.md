# 한국어·영어 학습 사용성 관찰 프로토콜

작성일: 2026-08-30  
대상: NumberCal 한국어·영어 학습 놀이터  
목적: 실제 어린이가 설명 없이 시작하고, 부담 없이 끝내며, 다음에 하고 싶은 학습을 고를 수 있는지 확인한다.

## 1. 참여자와 보호 원칙

- 유치원, 초등 1~2학년, 초등 3~6학년에서 각각 5명 이상을 관찰한다.
- 보호자 동의를 먼저 받고, 이름·학교·얼굴·음성을 수집하지 않는다.
- 점수나 순위를 비교하지 않는다. 아이가 중단해도 보상·기록에 불이익이 없다고 안내한다.
- 진행자는 답을 알려주지 않는다. 막힌 상황은 “어떻게 해 보고 싶어?”만 한 번 묻고 관찰한다.

## 2. 준비

- 인터넷 연결 상태와 한 번 설치한 뒤의 오프라인 상태를 각각 준비한다.
- 어린이용 기기는 320px 폭 휴대전화 또는 태블릿 1대, 관찰 기록지는 별도 기기 1대를 사용한다.
- 처음 참여자는 기존 기록이 없는 상태에서 시작한다. 이어 하기와 기록 파일 복원은 보호자 시나리오에서만 확인한다.

## 3. 15분 관찰 흐름

| 순서 | 아이에게 보여 줄 상황 | 관찰할 행동 | 통과 기준 |
|---|---|---|---|
| 1 | 홈에서 “오늘 하고 싶은 것을 골라 볼까?” | 과목과 작은 모험 선택 | 설명 없이 30초 안에 시작 |
| 2 | 한국어 또는 영어 첫 언어 놀이 | 시범을 보고 첫 답 고르기 | 도움 없이 첫 문제 진입 |
| 3 | 두 번 연속 어려운 문제 | 힌트·그림·느린 다시 듣기 사용 | 좌절 표현 없이 대체 도움 사용 |
| 4 | 5문제 작은 모험 | 중단·다시 시작·다음 친구 선택 | 80% 이상이 세션 완료 |
| 5 | 결과와 성장 숲 | 오늘 만난 것과 다음 추천 이해 | 아이 말로 한 가지 설명 |
| 6 | 보호자만: 설정의 기록 옮기기 | 파일 미리보기 뒤 복원 | 개인정보 없이 안전하게 복원 |
| 7 | 설치 뒤 오프라인으로 전환 | 홈, 언어 놀이, 이야기 진입 | 핵심 화면과 저장 기록 유지 |

## 4. 기록 항목

각 참여자에 대해 아래만 익명 코드로 적는다.

- 첫 문제 시작까지 걸린 시간과 진행자 도움 횟수
- 세션 완료 여부와 중단한 문제 위치
- 힌트·다시 듣기·그림을 스스로 사용했는지
- 읽기·듣기·타일 조립 중 멈춘 활동과 관찰된 이유
- “다음에 무엇을 하고 싶어?”에 대한 자유 응답
- 보호자의 기록 파일 만들기·미리보기·복원 성공 여부
- 오프라인 상태에서 보인 오류 또는 혼란

## 5. 합격과 개선 판단

- 유치원 참여자 80% 이상이 추가 설명 없이 첫 문제를 시작한다.
- 전체 참여자 80% 이상이 작은 모험을 끝낸다.
- 같은 화면에서 두 명 이상이 멈추면 문구·그림·터치 위치를 개선 후보로 등록한다.
- 한 활동에서 세 명 이상이 힌트 뒤에도 진행하지 못하면 난이도·오답·시범을 재검토한다.
- 기록 복원 또는 오프라인 진입이 한 번이라도 실패하면 해당 기기·브라우저·단계를 재현해 출시 전 수정한다.

## 6. 관찰 뒤 처리

1. 익명 관찰 기록을 집계해 성공 기준과 막힌 지점을 분리한다.
2. 콘텐츠·힌트·활동 순서 변경은 콘텐츠 품질 게이트와 6종 학습자 시뮬레이션을 다시 통과시킨다.
3. 수정하지 않은 원본 관찰 기록은 보호자 동의 범위가 끝나면 폐기한다.
